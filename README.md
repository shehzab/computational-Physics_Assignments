# Computational Physics Assignments

This repo is for college purpose — physics-based maths problems solved using Python code.

## Folders

- `taylor_series_exp` — Approximating e^x using Taylor series expansion
- `sum_of_squares` — Sum of squares computed via loop and verified with a formula
- `star_diagonal` — Nested double sum problem (diagonal sums)
- `convergance_loop` — Square root calculation using the bisection method

## Requirements

- Python 3.x
